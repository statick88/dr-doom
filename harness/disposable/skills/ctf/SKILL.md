# CTF

1. Confirma que es un reto/laboratorio y registra objetivo, archivos y regla de bandera.
2. Enumera artefactos locales antes de inferir una técnica. Mantén una tabla: evidencia, hipótesis, prueba segura y resultado.
3. Trabaja de lo reversible a lo costoso: formato, metadatos, parsing y reproducción mínima. No conviertas una pista en tráfico hacia un tercero.
4. Para una solución, entrega pasos, comandos ejecutados, salida relevante y condiciones para reproducirla. Una bandera o crash no demuestra una vulnerabilidad real fuera del reto.
