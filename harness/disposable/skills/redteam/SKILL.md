# Red team

1. Obtén ROE aprobadas: patrocinador, objetivos, alcance, exclusiones, contactos de emergencia, ventanas, datos permitidos y criterios de stop.
2. Relaciona cada objetivo con una técnica ATT&CK y una telemetría esperada. ATT&CK orienta cobertura; no autoriza una acción.
3. Define éxito y evidencia antes de actuar. Prefiere simulación y evidencia local cuando el alcance externo no esté confirmado.
4. Para cada acción, registra objetivo, técnica, hora, operador, resultado y detección. No declares evasión ni compromiso sin evidencia verificable.
5. Detente y notifica ante impacto, acceso a datos no permitidos, cambio de alcance, alerta de emergencia o pérdida de comunicación. No continúes para “confirmar”.
